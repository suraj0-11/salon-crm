# Suresh Gents Beauty Parlor

A mobile-friendly daily salon ledger with three screens: Today, People, and Summary.

Open `index.html` in a modern browser. There is no build step.

- Add workers from **People** and choose their role. The salon has one owner profile; selecting Owner updates that name.
- On **Today**, choose who performed the service, enter the cost, and optionally add a short description. The split updates immediately.
- **Summary** shows the total service value, each worker’s 50% earnings, the owner’s 100% own-service earnings, the salon’s 50% share from worker work, and the owner’s total.
- Use the date controls to add or review earlier days.

Entries are stored in this browser. Existing ledger entries are migrated automatically.
